# 🏆 Gold Mining Clicker — Инструкция по запуску и тестированию

## 📦 Структура проекта

```
gold-mining-game/

```

## 🚀 Как запустить

### Вариант 1: Локальный запуск (рекомендуется)
1. Откройте файл `index.html` в любом современном браузере:
   - **Windows/Mac**: Дважды кликните по файлу
   - **Linux**: `xdg-open index.html` или перетащите в браузер

### Вариант 2: Через локальный сервер
```bash
# Python 3
python -m http.server 8000

# Node.js (требуется http-server)
npx http-server -p 8000

# Затем откройте http://localhost:8000
```

### Вариант 3: Мобильное тестирование
1. Загрузите файл на любой хостинг (GitHub Pages, Netlify, Vercel)
2. Откройте ссылку на смартфоне/планшете
3. Или используйте Chrome DevTools → Device Mode для эмуляции

## 🧪 Тестирование функциональности

### 1. Базовый геймплей

### 2. Система улучшений
- [ ] Протестируйте все 4 вкладки:
  - ⛏️ **Улучшения** (инструменты)
  - 🔬 **Исследования** (дерево технологий)
  - 👥 **Персонал** (шахтёры, инженеры)
  - 🏭 **Инфраструктура** (постройки)
- [ ] Проверьте рост стоимости улучшений
- [ ] Убедитесь, что недоступные улучшения серые

### 3. Исследования
- [ ] Накопите 500+ золота
- [ ] Изучите «Геологоразведку» в ветке «Добыча»
- [ ] Проверьте, что следующие технологии открываются только после предыдущих
- [ ] Убедитесь, что бонусы применяются к добыче

### 4. Оффлайн-прогресс
1. Добудте немного золота и наймите персонал (чтобы был GPS > 0)
2. Закройте вкладку/браузер
3. Подождите 10+ секунд
4. Откройте игру снова
5. Должно появиться уведомление о оффлайн-доходе

### 5. Сохранения
- [ ] Автосохранение происходит каждые 10 секунд (индикатор внизу слева)
- [ ] При закрытии вкладки сохранение происходит автоматически
- [ ] После перезагрузки страницы прогресс сохраняется
- [ ] Кнопка «Сбросить сохранение» в настройках работает

### 6. Престиж-система
1. Накопите 1,000,000+ total золота
2. Нажмите кнопку «Престиж» в правой панели
3. Проверьте расчёт Слитков Вечности
4. Подтвердите престиж
5. Убедитесь, что:
   - Золото сброшено
   - Улучшения сброшены
   - Слитки Вечности сохранены
   - Бонус применяется к новой игре

### 7. Динамические события
- [ ] Подождите случайное событие (шанс 1% в секунду)
- [ ] Проверьте таймер события в правой панели
- [ ] Убедитесь, что бонус/штраф применяется correctly

### 8. Достижения
- [ ] Разблокируйте несколько достижений:
  - «Первое золото» (автоматически)
  - «Упорство» (100 кликов)
  - «Прогресс» (купите улучшение)
- [ ] Проверьте уведомления о разблокировке

### 9. Производительность
- [ ] Откройте DevTools → Performance
- [ ] Убедитесь, что FPS стабилен (~60)
- [ ] Включите «Режим производительности» в настройках
- [ ] Проверьте, что частицы отключились

### 10. Адаптивность

## 🏗️ Архитектура игры

### Структура состояния (Game.state)
```javascript
{
  gold: number,              // Текущее золото
  totalMined: number,        // Всего добыто за всё время
  prestige: {                // Престиж-система
    count: number,           // Количество слитков
    bonus: number            // Текущий бонус (10% за слиток)
  },
  tools: { id: level },      // Уровни инструментов
  miners: { id: level },     // Уровни шахтёров
  engineers: { id: level },  // Уровни инженеров
  buildings: { id: level },  // Уровни построек
  research: [id],            // Изученные технологии
  achievements: [id],        // Разблокированные достижения
  stats: {                   // Статистика
    totalClicks: number,
    totalMined: number,
    upgradesPurchased: number,
    playTime: number,
    startTime: timestamp
  },
  settings: {                // Настройки
    performanceMode: boolean,
    soundEnabled: boolean
  },
  activeEvent: {             // Активное событие (опционально)
    id, name, description, endTime, effect
  },
  lastSave: timestamp,       // Время последнего сохранения
  lastOnline: timestamp      // Время последней сессии
}
```

### Игровой цикл (Game Loop)
```
requestAnimationFrame → gameLoop(timestamp)
  ├─ Расчёт deltaTime
  ├─ Обновление времени игры
  ├─ Начисление пассивного дохода (GPS × deltaTime)
  ├─ Обновление событий
  ├─ Рендер UI (UI.updateDisplay)
  ├─ Обновление частиц (Particles.update)
  └─ Автосохранение (каждые 10 сек)
```

### Система обновлений UI
- **Batched updates**: Все изменения DOM происходят в одном вызове `updateDisplay()`
- **CSS transforms**: Анимации используют `transform` и `opacity` (без reflow)
- **Canvas particles**: Частицы рендерятся на отдельном Canvas без влияния на DOM
- **Debounce**: Сохранение debounce'ится на 5 секунд

### План расширения

#### Добавление нового улучшения:
1. Добавьте объект в соответствующий массив (TOOLS/MINERS/ENGINEERS/BUILDINGS):
```javascript
const TOOLS = [
  // ...
  { id: 'new_tool', name: 'Название', baseCost: 1000, basePower: 25, description: '...' }
];
```
2. Игра автоматически отобразит улучшение в UI

#### Добавление новой технологии:
1. Добавьте в RESEARCH_TREE в нужную ветку:
```javascript
technologies: [
  { 
    id: 'new_tech', 
    name: 'Название', 
    cost: 5000, 
    description: '+50% бонус', 
    effect: { type: 'global_mult', value: 0.5 }, 
    prerequisites: ['mining_1'] 
  }
]
```

#### Добавление нового события:
```javascript
const EVENTS = [
  { 
    id: 'new_event', 
    name: 'Событие', 
    description: 'x5 добыча', 
    duration: 60000, 
    effect: { type: 'global_mult', value: 5.0 }, 
    icon: '🎉' 
  }
];
```

#### Добавление достижения:
```javascript
const ACHIEVEMENTS = [
  { 
    id: 'new_achievement',

    description: 'Условие', 
    condition: (state) => state.gold >= 1000000, 
    icon: '🏆' 
  }
];
```

## ⚙️ Технические особенности

### Производительность
- ✅ **requestAnimationFrame** вместо setInterval
- ✅ **Delta time** для независимости от FPS
- ✅ **Canvas 2D** для частиц (не DOM)
- ✅ **CSS will-change** для анимаций
- ✅ **Debounce** для сохранений
- ✅ **Page Visibility API** для паузы

### Кроссплатформенность
- ✅ **Viewport meta** для мобильных
- ✅ **Pointer events** для mouse/touch
- ✅ **CSS Grid/Flex** для адаптивности
- ✅ **Media queries** для разных экранов
- ✅ **Auto performance mode** для слабых CPU

### Безопасность данных
- ✅ **localStorage** с JSON serialization
- ✅ **Safe JSON parse** с fallback
- ✅ **Сохранение при unload**
- ✅ **Сохранение при visibilitychange**
- ✅ **Лимит оффлайн-времени** (24 часа)

### Работа с числами
- ✅ **Автоматический форматтер** (K, M, B, T...)
- ✅ **Защита от переполнения**
- ✅ **BigInt поддержка** (опционально)

## 🐛 Troubleshooting

**Игра не загружается:**
- Проверьте консоль браузера (F12)
- Убедитесь, что JavaScript включён
- Попробуйте другой браузер

**Сохранения не работают:**
- Проверьте, не заблокирован ли localStorage
- Очистите кэш браузера
- Убедитесь, что используете http/https (не file://)

**Низкая производительность:**
- Включите «Режим производительности» в настройках
- Закройте другие вкладки
- Обновите браузер

**Оффлайн-прогресс не считается:**
- Убедитесь, что был GPS > 0 перед закрытием
- Проверьте, что прошло больше 5 секунд
- Убедитесь, что localStorage работает
