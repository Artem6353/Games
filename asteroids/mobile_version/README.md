# 🎮 NEON ASTEROIDS - Mobile Version

Браузерная мобильная версия игры Neon Asteroids в одном HTML-файле.

## 🚀 Быстрый старт

### Вариант 1: Локальный запуск
Просто откройте файл `index.html` в любом современном браузере на телефоне или компьютере.

```bash
# На телефоне - откройте файл через файловый менеджер
# На ПК - дважды кликните по файлу или перетащите в браузер
```

### Вариант 2: Через локальный сервер
```bash
# Python
python -m http.server 8000

# Node.js
npx http-server

# Затем откройте в браузере: http://localhost:8000/mobile_version/
```

### Вариант 3: Деплой на хостинг
Загрузите файл `index.html` на любой статический хостинг:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting

## 📱 Управление

### Сенсорное управление:
- **Левый джойстик** - Тяга (вперёд)
- **Правый джойстик** - Поворот корабля
- **Красная кнопка FIRE** - Стрельба

### Геймплей:
1. Уничтожайте астероиды
2. Собирайте оранжевые "Осколки ядра"
3. Поддерживайте комбо (попадания без промахов)
4. Между волнами покупайте улучшения в магазине
5. Выживайте как можно дольше!

## ⚙️ Технические особенности

### Реализованные системы:
✅ **Object Pooling** - Пулы объектов для пуль, астероидов, частиц и осколков  
✅ **Spatial Hash Grid** - Оптимизированная проверка коллизий  
✅ **Delta Time** - Плавная работа на любых FPS  
✅ **Векторная физика** - Инерция, трение, максимальная скорость  
✅ **Тороидальное пространство** - Wrap-around эффект  
✅ **Система частиц** - Взрывы, шлейф от двигателя  
✅ **Camera Shake** - Тряска экрана при уроне и взрывах  
✅ **Combo система** - Множитель до x5.0  
✅ **Магазин улучшений** - 4 типа прокачки  
✅ **Адаптивный дизайн** - Работает на всех размерах экрана  

### Оптимизация для мобильных:
- `touch-action: none` - Отключение стандартных жестов браузера
- `user-select: none` - Запрет выделения текста
- Мультитач поддержка - Одновременная работа обоих джойстиков
- Адаптивные контролы - Подстраиваются под размер экрана
- Полноэкранный режим - На весь экран устройства

## 🎯 Характеристики игры

### Корабль:
- Максимальная скорость: 300 px/s (прокачивается)
- Ускорение: 400 px/s²
- Трение: 0.98
- Здоровье: 100 HP

### Астероиды:
- **Большие** (розовые) - 3 HP, распадаются на 2 средних
- **Средние** (голубые) - 2 HP, распадаются на 2 маленьких
- **Маленькие** (жёлтые) - 1 HP, уничтожаются полностью

### Улучшения в магазине:
| Улучшение | Базовая цена | Эффект |
|-----------|--------------|--------|
| 🚀 Max Speed | 10 ядер | +50 px/s к скорости |
| 🔫 Fire Rate | 15 ядер | -0.03s к перезарядке |
| 💥 Damage | 20 ядер | +0.5 к урону |
| 🧲 Magnet | 12 ядер | +30px к радиусу магнита |

Цена растёт с каждым уровнем: `baseCost * (level + 1)`

## 🎨 Визуальный стиль

- **Неоновый wireframe** - Векторная графика с эффектом свечения
- **Цветовая схема**:
  - Корабль: голубой (#00ffff)
  - Большие астероиды: розовый (#ff00ff)
  - Средние астероиды: голубой (#00ffff)
  - Маленькие астероиды: жёлтый (#ffff00)
  - Пули: жёлтый (#ffff00)
  - Осколки: оранжевый (#ffa500)
  - Частицы: белые с затуханием

```javascript
const GAME_CONFIG = {

    SHIP_MAX_SPEED: 300,
    SHIP_ACCELERATION: 400,
    // ... другие параметры
};
```

- **60+ FPS** на современных смартфонах
