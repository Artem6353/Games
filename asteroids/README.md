# NEON ASTEROIDS - Production Edition

Профессиональная реализация классической игры Asteroids на Python с использованием Pygame.

## Особенности

### Технические
- **Object Pooling**: Пулы объектов для пуль, астероидов, частиц и осколков для предотвращения аллокаций памяти во время игры
- **Spatial Hash Grid**: Пространственное хеширование для оптимизированной проверки коллизий O(1) вместо O(n²)
- **Delta Time**: Вся физика независима от FPS благодаря умножению на dt
- **Строгая типизация**: Полные type hints для всех классов и методов
- **Модульная архитектура**: Разделение логики рендеринга, физики и ввода

### Игровые механики
- **Инерционная физика**: Корабль имеет разгон, максимальную скорость и трение
- **Тороидальное пространство**: Объекты плавно появляются с противоположной стороны экрана
- **Разрушаемые астероиды**: Большие → Средние → Маленькие с увеличением скорости
- **Система комбо**: Множитель очков за последовательные попадания без промахов
- **Магнитный сбор**: Осколки ядра притягиваются при приближении

### Meta-progression
- **Магазин улучшений** между волнами:
  - Максимальная скорость корабля (+15% за уровень)
  - Скорострельность (-12% перезарядки за уровень)
  - Урон снарядов (+25% за уровень)
  - Радиус магнита (+30% за уровень)

### Визуальные эффекты (Juice)
- **Система частиц**: Взрывы, искры, следы от двигателя
- **Camera Shake**: Тряска экрана при повреждениях и взрывах
- **Пульсирующий UI**: Анимация комбо-счетчика
- **Неоновый стиль**: Wireframe графика в стиле ретро-аркад

## Управление

- **WASD / Стрелки**: Поворот и тяга
- **SPACE**: Стрельба
- **ESC**: Пауза / Магазин
- **ENTER**: Подтверждение / Старт
- **1-4**: Покупка улучшений в магазине

## Архитектура

### Основные классы

#### Ядро движка
- `GameManager` - Главный менеджер игры, координирует все системы
- `GameState` - Перечисление состояний (MENU, PLAYING, SHOP, GAME_OVER)

#### Система пулов
- `ObjectPool[T]` - Универсальный пул объектов
- `Poolable` - Абстрактный базовый класс для пулируемых объектов

#### Оптимизация
- `SpatialGrid` - Пространственная сетка для коллизий

#### Игровые объекты
- `GameObject` - Базовый класс всех объектов
- `Ship` - Корабль игрока
- `Bullet` - Снаряды
- `Asteroid` - Астероиды (3 размера)
- `Particle` - Частицы эффектов
- `CoreFragment` - Собираемая валюта

#### Системы
- `ComboSystem` - Система комбо-множителей
- `ShopSystem` - Магазин улучшений
- `CameraShake` - Эффект тряски камеры

## Настройки баланса

В начале файла `main.py` находятся константы для настройки:

```python
# Экран
SCREEN_WIDTH = 1280
SCREEN_HEIGHT = 720
FPS = 60

# Корабль
SHIP_THRUST = 400.0
SHIP_MAX_SPEED = 400.0
SHIP_FRICTION = 0.98

# Комбо
COMBO_MULTIPLIER_STEP = 0.1
MAX_COMBO_MULTIPLIER = 5.0

# Стоимость улучшений
UPGRADE_COSTS = {
    'max_speed': [100, 200, 400, 800, 1600],
    'fire_rate': [150, 300, 600, 1200, 2400],
    ...
}
```

## Расширение

Код готов к расширению благодаря модульной архитектуре:

1. **Новые типы врагов**: Наследуйте от `GameObject` и добавьте в пул
2. **Новые улучшения**: Добавьте в `UpgradeType` и `ShopSystem`
3. **Боссы**: Создайте класс с особыми паттернами движения
4. **Power-ups**: Добавьте собираемые объекты с временными эффектами

## Производительность

Оптимизации обеспечивают стабильные 60 FPS даже при:
- 50+ активных частицах
- 20+ астероидах одновременно
- Интенсивной стрельбе

Object Pooling предотвращает сборку мусора, Spatial Grid сокращает проверки коллизий с O(n²) до O(n).
